# Проверка стереоимпорта

Архивный замер от 22 ноября 2026 года. В таблицах указаны ревизии, на которых его выполняли. Для версии 0.5.10 нужен отдельный прогон.

Проверен настоящий `audio_import.normalize` Mac на PCM16 stereo WAV 16 кГц. Тот же исходный стереофайл передан отдельному адаптеру выбора канала. Два известных фрагмента, 26 слов в каждом условии.

| Стереоусловие | Ошибки downmix | Ошибки выбора |
| --- | ---: | ---: |
| Близкий голос и удалённый шумный канал | 0 | 0 |
| Сильный шум справа | 26 | 0 |
| Сильный шум слева | 26 | 0 |
| Клиппинг справа | 0 | 0 |
| Клиппинг слева | 0 | 0 |
| Противофаза | 26 | 0 |
| Тишина слева | 0 | 0 |
| Одинаковые каналы | 0 | 0 |
| Моно | 0 | 0 |

Шесть тестов прошли. Проверены отсутствие VAD на моно, неизменность входных отсчётов, противофаза, клиппинг, постоянный канал и отсутствие речи. Для моно и одинаковых каналов сохранён результат текущего импортёра, SHA выходных WAV совпал побайтово. Исходные файлы не изменялись.

## Граница интеграции

Опытный модуль `tools/speech_channels.py`: `choose_speech_channel(analysis_pcm, speech_ranges=None) -> (0 | 1 | None, metrics)`. Вход — короткий PCM-фрагмент 16 кГц с раздельными каналами; `None` означает оставить существующий импорт/downmix. Решение использует длительность речи обычного VAD, оценку шума, клиппинг и противофазу. Оно не устанавливает личность преподавателя.

Текущий `audio_import.normalize` не менялся. Для интеграции с MP3/M4A и прочими форматами нужен этап декодирования с сохранением каналов **до** mono-downmix, затем выбор и запись выбранного PCM. Готовый mono-WAV проходит прежний путь. Android-импортёр и интерфейс не менялись. Выбор канала по короткому фрагменту не проверен на меняющемся качестве всей 90-минутной стереозаписи.

**Физическая проверка:** нужны реальные два микрофона/канала, движения преподавателя и посторонний близкий голос. Нынешний результат относится к смоделированным каналам.

[WAV, решения, хеши и тексты](stereo-import-2026-11-22.json). Локальные входы и результаты: `work/stereo-import/`, `work/stereo-loud-import/`.
