# HAVRUS · лекции, доступ и микрофоны

Проверка 22 ноября 2026. HAVRUS подтверждён как корпус постановочной аудиовизуальной русской речи. Лекционная часть, общедоступный архив, условия выдачи и пометка расстояний у отдельных файлов пока не подтверждены.

[ФИПС](https://new.fips.ru/registers-doc-view/fips_servlet?DB=DB&DocNumber=2017621219&TypeFile=html) · [Статья авторов 2019 года](https://i-us.ru/index.php/ius/article/download/4732/2680) |

Прямой запрос к вложению статьи на сайте Ulm вернул HTTP 404. Содержание разделов сверено по индексированной копии статьи и отдельной публикации авторов. Для проверки через держателя нужен официальный ответ, существует ли речь длиннее подборки фраз, возможна ли локальная выдача для оценки ASR и что включает дорожечный паспорт. Для парной проверки нужны идентификатор общей записи, каналы, фактическая дистанция от рта до капсюля и синхронизация. Адрес лаборатории опубликован на странице контактов. Ответ держателя остаётся открытым.
