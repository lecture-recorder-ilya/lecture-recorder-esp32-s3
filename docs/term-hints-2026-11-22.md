# Подсказки предмета и защита отрицаний

Архивный замер от 22 ноября 2026 года. В таблицах указаны ревизии, на которых его выполняли. Для версии 0.5.10 нужен отдельный прогон.

Исправлен воспроизводимый дефект: подсказка могла заменить «зависимый» на «независимый» или стереть «не» в слове «неактивный». Такая пара теперь остаётся без замены и помечается для проверки. Защищены также распознанные формы числительных.

Словарь теперь принимает падежные формы известного термина через уже установленный pymorphy3. Подсказка «пробирка» может выбрать акустически распознанное «пробирку». Существующую допустимую форму термина не перегибаем в другой падеж. Словарь по-прежнему не вставляет слова: нужны кандидат другого декодера, близкий таймкод и совпавший сосед. Без словаря морфологии остаётся буквальное сопоставление.

Живые модели Mac, четыре известных фрагмента, 44 слова в каждом режиме:

| Режим | Ошибки | Числовые токены и отрицания |
| --- | ---: | --- |
| base | 10 / 44 | Совпали с базой |
| correct | 8 / 44 | Совпали с базой |
| wrong | 10 / 44 | Совпали с базой |

Подсказки исправили «пробилку» → «пробирку» и «этрам» → «мэтрам». Правильный словарь содержит начальные формы «пробирка» и «мэтр»; подстановка берёт произнесённую форму из акустического прохода. Для неверного предмета использованы «транзистор», «электрод», «диффузия», «кремний». На четырёх живых примерах результат неверного предмета совпал с базой; на 130 сохранённых акустических проходах также не было подстановок или новых изменений чисел/отрицаний.

Это целевые примеры известных слов, а не слепое измерение эффекта для всех дисциплин. Реальные участники для оценки настройки предмета и удобства словаря не привлекались. Ошибки, уже сделанные основным ASR, не считаются исправленными этой защитой.

ASR-ID обновлён до `GigaAM-v3-3pass-phrases-v12-term-forms-guard`, чтобы старый кэш не выдавался за новый алгоритм. Версия релиза не менялась. Прошли шесть новых тестов и 20 существующих ASR-регрессий.
