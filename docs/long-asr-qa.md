# Длинный контроль ASR

Отдельный набор из полных дорожек русских TEDx из архива mTEDx ru-en. Для каждого источника берётся одно непрерывное окно 120–150 с, полученное из исходного FLAC, без склейки фрагментов и добавления фона. Начало после первых 15 с, границы по оригинальным WebVTT, покрытие текстом не менее 80%. Для локальной оценки используется исходный человеческий текст субтитров. Субтитры могут сокращать речь и не являются новой дословной сверкой. Дистанции микрофонов неизвестны. [Архив и условия CC BY-NC-ND 4.0](https://www.openslr.org/100/) · [Статья авторов mTEDx](https://esalesky.github.io/assets/pdf/mtedx_interspeech2021.pdf)

Первые пять дорожек архива с подходящим окном отбираются в порядке TAR. Хеш от ID выступления задаёт порядок распределения. Два целых источника идут в настройку, три в контроль. Все окна одной лекции, а при известном `speaker_id` и одного спикера, должны остаться в одной части. `long-asr-control.json` фиксирует границы, хеши FLAC, VTT, WAV и текста. Аудио, VTT и гипотезы хранятся локально в `work/long-asr/`. Распределение задано по исходным лекциям. Пять имён выступающих из метаданных TEDx Talks сверены отдельно, пересечений между частями нет. Состав предобучения GigaAM неизвестен. [Таблица по исходным лекциям и исключению спикера](long-asr-results.md)

## Повторить

```sh
repo="$(git rev-parse --show-toplevel)"
python=python3
manifest="$PWD/work/long-asr/control/manifest.json"
"$python" tools/asr_qa.py run "$manifest" --lock docs/long-asr-control.json \
  --source-root "$candidate" --output work/long-asr/runs/next-mac.json
```

`$candidate` — отдельная рабочая копия проверяемого коммита с доступными локальными весами в `work/models`. Длинный набор использует штатный Mac `qwen_transcribe.run` с контрольными точками, выключены ожидания экономичного режима. Измерение охватывает распознавание и запись контрольных точек. Для восстановления одинакового манифеста `tools/prepare_long_asr.py` принимает оригинальный `mtedx_ru-en.tgz` или его непрерывный префикс, содержащий все пять полных FLAC и VTT.

## Целые записи

Те же исходные лекции собраны и в полном размере. Локальный набор `work/long-asr/full/` содержит 51 мин 20 с в пяти WAV. Проверены полные длительности, хеши источников и совпадение распределения с набором окон. Субтитры у целых записей могут покрывать речь не полностью. WER для окон и для целых дорожек считать отдельно.

```sh
python3 tools/prepare_long_asr.py work/long-asr/source/mtedx.partial.tgz work/long-asr/full --full
"$python" tools/asr_qa.py run work/long-asr/full/manifest.json --lock docs/long-asr-full-control.json \
  --source-root "$candidate" --output work/long-asr/runs/next-full-mac.json
```

Локальный непрерывный префикс исходного архива содержит 188 575 744 байта. SHA-256 — `913fe822e35779f43ef7adf5190cca56280fa404d05af2ea1298a71fa2c9940a`.

## Восемь фраз для сверки

В локальном `work/long-asr/review/` лежат восемь коротких WAV из контрольных источников. Четыре отобраны по числам и четыре по отрицаниям в исходных субтитрах. Отбор выполнен по тексту и таймкодам до открытия гипотез. SHA-256 исходного пакета `review.json` — `b07ecbc6d777279431cd309df80c2c03032500a0a0cbe4f6b138dfd770d6ff28`.

- `subtitles` — оригинальный текст WebVTT с исходным таймкодом.
- `machine` — отдельный файл со словами гипотезы, середина таймкода которых попала в интервал. Пустое поле означает отсутствие выбранных слов с таймкодами.
- `manual_verified` — запись прослушавшего с дословным текстом, датой, псевдонимом проверяющего и SHA-256 короткого WAV. Сначала прослушать WAV и записать услышанное, затем открыть субтитры и сравнить. Сейчас `manual_review` пуст у всех восьми фраз.

```sh
python3 tools/prepare_lecture_review.py check work/long-asr/review/review.json
python3 tools/prepare_lecture_review.py machine work/long-asr/review/review.json \
  work/long-asr/runs/68f2236-mac.decoded.json work/long-asr/review/68f2236-machine.json
```
