# Что вышло с распознаванием дальнего звука

Архивный замер от 22 ноября 2026 года для v0.5.9 и экспериментальных ревизий.

Сравнил тег `v0.5.9` (`6abca7c`) и эксперимент на Маке. Веса GigaAM одинаковые. В каждом прогоне сверил ID фрагментов и SHA-256 WAV. Ниже количество ошибок по словам. Оно включает замены, пропуски и вставки. Эталон OpenSTT и mTEDx взят из субтитров, которые могут сокращать речь.

| Набор | Фрагменты | Слов в эталоне | 0.5.9 → эксперимент |
| --- | ---: | ---: | ---: |
| Реальные лекции OpenSTT, две контрольные выборки | 72 | 770 | 85 → 85 (11,04%) |
| Те же фрагменты с добавленным шумом и отражениями, +6 дБ | 72 | 770 | 170 → 170 (22,08%) |
| Реальные выступления mTEDx с исходным фоном | 18 | 366 | 84 → 84 (22,95%) |
| Golos Farfield, короткие команды | 24 | 150 | 18 → 18 (12,00%) |
| Тишина и шум в трёх контрольных прогонах, две контрольные дорожки | 6 проверок | 0 | 0 → 0 лишних слов |

На выборке настройки из 18 исходных фрагментов получилось 27 → 27 ошибок. У их копий с комнатой вышло 49 → 47. В одном клипе вернулось начало «Он сказал». На двух контрольных выборках лекций эффект не повторился.

В эксперименте второй проход ищет короткий тихий звук рядом с уже найденной речью. Фрагмент может вернуться только с края, если весь имеющийся текст совпал и у добавленных слов есть таймкоды и достаточная уверенность. Добавленные слова помечаются для прослушивания. Числа и отрицания остаются за этим фильтром. Оригинальные WAV не меняются. Простое снижение порога давало 81 → 84 ошибки на первой контрольной выборке с комнатой. Усиленная очистка и подъём громкости тоже проиграли на выборке настройки.

Для Android проверен отдельный декодер в настольной JVM. Общего выигрыша на контрольных WAV не получилось. [Что проверили на Android](android-rear-row-2026-11-22.md)

Расстояние до микрофона OpenSTT и mTEDx неизвестно. В Golos авторы использовали студийные записи на расстояниях 1, 3 и 5 метров, но в полученной выборке нет расстояния для каждой дорожки. Замер реальной пары с последнего ряда остаётся отдельной проверкой. [OpenSTT](https://github.com/snakers4/open_stt) · [mTEDx](https://www.openslr.org/100/) · [Методика Golos](https://www.isca-archive.org/interspeech_2021/karpov21_interspeech.pdf)

## Как повторить

Скачай [архив лекций OpenSTT](https://zenodo.org/records/4899885/files/public_lecture_1.tar.gz?download=1), [индекс](https://azureopendatastorage.blob.core.windows.net/openstt/ru_open_stt_opus/manifests/public_lecture_1.csv) и при необходимости [индекс Golos Farfield](https://datasets-server.huggingface.co/first-rows?dataset=bond005%2Fsberdevices_golos_100h_farfield&config=default&split=test). Подготовка использует `afconvert` на Маке и зависимости из среды распознавания. После конвертации корпуса остаются локально.

```sh
git worktree add --detach work/rear-row-base v0.5.9
ln -s "$PWD/work/models" work/rear-row-base/work/models
python3 tools/prepare_rear_row_asr.py \
  public_lecture_1.tar.gz public_lecture_1.csv work/rear-row-wav \
  --golos-index golos-test-rows.json
python3 tools/prepare_rear_row_asr.py \
  public_lecture_1.tar.gz public_lecture_1.csv work/rear-row-extra \
  --skip 54 --development 1 --holdout 36

python3 tools/evaluate_asr.py work/rear-row-wav/holdout.json \
  --source-root work/rear-row-base --output work/rear-row-wav/old.json
python3 tools/evaluate_asr.py work/rear-row-wav/holdout.json \
  --output work/rear-row-wav/new.json
python3 tools/evaluate_asr.py work/rear-row-wav/holdout.json \
  --compare 0.5.9=work/rear-row-wav/old.json \
  --compare эксперимент=work/rear-row-wav/new.json --output work/rear-row-wav/compare.json
```

Для второй контрольной выборки повтори команды с `work/rear-row-extra/holdout.json`. Подготовка mTEDx описана в [ASR.md](../ASR.md).
