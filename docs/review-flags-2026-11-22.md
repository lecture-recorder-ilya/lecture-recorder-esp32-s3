# Пригодность флага «сомнительно»

Архивный замер от 22 ноября 2026 года. В таблицах указаны ревизии, на которых его выполняли. Для версии 0.5.10 нужен отдельный прогон.

Флаг относится к фразе. На замороженном контроле он охватывает 115 из 177 словесных ошибок (65,0%). Среди 70 полностью безошибочных фраз помечена 31 (44,3%). Из 79 тревог 48 относятся к фразам с ошибками: точность тревоги 60,8%. Отсутствие флага здесь пропускает 35% ошибок.

| Ошибки в группе | База: охвачено / всего | Кандидат | Ложные тревоги базы на безошибочных фразах группы |
| --- | ---: | ---: | ---: |
| Все | 115 / 177 (65.0%) | 116 / 177 (65.5%) | 31 / 70 (44.3%) |
| Короткие слова, ≤3 букв | 58 / 88 (65.9%) | 58 / 88 (65.9%) | 28 / 56 (50.0%) |
| Термины фиксированного словаря | 4 / 4 (100.0%) | 4 / 4 (100.0%) | 0 / 1 (0.0%) |

Для терминов в контроле всего четыре ошибки и одна безошибочная фраза со словарным термином. Этих знаменателей недостаточно для общего вывода о надёжности флага на профессиональной терминологии.

## Опыт улучшения

Правило выбрано только на development: локальные признаки слов вместо общего CTC-порога; сохранены специальные причины проверки, исправления и возможные пропуски речи. Порог зафиксирован до вычисления контрольных метрик. На настройке число ложных тревог снизилось с 9/24 до 8/24 при том же охвате ошибок 54/74.

На контроле ложные тревоги остались 31/70. Охват ошибок вырос только со 115/177 до 116/177; для коротких слов остался 58/88. Вариант не прошёл требование снижения ложных тревог и в приложение не перенесён.

## Метод

Настройка — 38 WAV прежнего development; контроль — 92 WAV проверяющего чата. Для метрик использованы исходные ответы 68f2236 с сохранёнными флагами и уверенность каждого слова. Набор контроля и SHA ответов записаны до подбора правил. Ни аудио, ни тексты, ни ASR-модели этот опыт не меняет. Численные метрики подсчитаны по 147 фразам с речевым эталоном; контроль без речи исключён из знаменателя ложных тревог.

Ошибки размечены фиксированным выравниванием Левенштейна с корпусными субтитрами. Пропуск отнесён к следующему распознанному слову, в конце — к последнему. Полностью потерянная речь учтена как виртуальная фраза без интерфейсного флага. Группы определяются по эталонному слову, для вставок — по вставленному; короткие слова только буквенные. Термины и морфологические формы ограничены заранее записанным словарём. Подсчёт не заменяет ручное прослушивание каждого расхождения субтитров с речью.

**Реальные участники:** оценка времени проверки, понятности флага и утомления слушателей не проводилась. Следующий пользовательский тест должен проверять, удаётся ли человеку находить ошибки быстрее с этими тревогами. Для числа ложных тревог по терминам нужен более широкий размеченный набор.

Четыре теста метрик прошли: пропуски коротких слов, пустая расшифровка, ложная тревога на правильном термине, отсутствие словесной уверенности. [Метрики, заморозка и размеченные фразы](review-flags-2026-11-22.json).
