# Независимый контроль распознавания

Архивный замер от 22 ноября 2026 года. В таблицах указаны ревизии, на которых его выполняли. Для версии 0.5.10 нужен отдельный прогон.

`asr-qa-control.json` фиксирует состав до запуска декодеров. В нём источники, условия записи, ID и SHA-256 WAV и эталонов. Сами эталоны, гипотезы и звук лежат локально в `work/asr-qa/`. «Реальные лекции» в таблице означает исходные фрагменты OpenSTT с человеческой разметкой корпуса. Эталон mTEDx — субтитры новых выступлений с таймкодами. Оба вида эталонов могут сокращать речь.

## Состав

- **OpenSTT** — 24 новых фрагмента 4,5–14 с. Убраны совпадения по ID и нормализованному эталону с четырьмя прошлыми манифестами. Из текстов без просмотра гипотез выбраны по восемь примеров с числом, с отрицанием и на общую речь. Порядок внутри групп задан SHA-256 от ID с фиксированным seed. Архив не раскрывает принадлежность к отдельной лекции. [OpenSTT и условия использования](https://github.com/snakers4/open_stt#links)
- **mTEDx** — 18 новых фрагментов по 5–17 с из трёх выступлений, целиком отличных от выступлений прошлого контроля. По два примера на каждую категорию в каждом выступлении. Подготовка использует зафиксированный Parquet русской части test. [mTEDx и лицензия](https://www.openslr.org/100/)
- **Модель комнаты** — 24 шумные копии выбранных OpenSTT, +6 дБ SNR, с отражениями и ограничением полосы. Хеш оригинала указан у каждой копии.
- **Golos и сигнал без речи** — 24 прежние короткие команды и два синтетических контроля. Это проверка воспроизводимости, с новыми лекциями её не суммируем. Дистанция 1/3/5 м описана для сбора всего Farfield. Для отдельных файлов в используемой разметке расстояния и пары неизвестны. [Методика Golos](https://www.isca-archive.org/interspeech_2021/karpov21_interspeech.pdf)

У «Рассказов и разговоров о грушах» есть синхронные индивидуальный и общий микрофоны и ручные таймкоды. Документация описывает размещение общего микрофона, численных расстояний для дорожек в ней нет. Проверка одной речи на известных расстояниях остаётся открытой. [Корпус](https://multidiscourse.ru/corpus/) · [Оборудование](https://multidiscourse.ru/solutions/)

## Подсчёт

WER считается по словам после приведения регистра, `ё` и удаления пунктуации. В локальном JSON есть подмены, пропуски и вставки. Один пропуск фразы — не менее трёх подряд удалённых токенов эталона в пословном выравнивании. Пустые расшифровки и лишние слова на записях без речи учитываются отдельно. Числовые токены и частицы `не`, `ни`, `нет`, `без` сверяются по позициям. Подмена учитывается с обеих сторон, если оба токена принадлежат классу. Цифры и словесные формы различаются. Каждое условие записи имеет отдельную строку WER.

## Повторить

Из QA-копии, с `python` среды распознавания и весами в `work/models` проверяемой копии. Для mTEDx нужен Python с `pyarrow`, для OpenSTT — среда распознавания, для конвертации — macOS `afconvert`.

```sh
repo="$(git rev-parse --show-toplevel)"
python=python3
manifest="$PWD/work/asr-qa/control/manifest.json"
candidate="$PWD/work/asr-qa/checkouts/68f2236"  # замени на рабочую копию нового кандидата
"$python" tools/asr_qa.py run "$manifest" --lock docs/asr-qa-control.json \
  --source-root "$candidate" --output work/asr-qa/runs/next-mac.json
"$python" tools/asr_qa.py compare work/asr-qa/runs/v059-mac.json work/asr-qa/runs/next-mac.json
```

Тот же запуск для Android JVM получает `--android --jdk "$jdk" --deps "$deps" --model "$ctc_model"` и отдельный путь результата. База и кандидат должны иметь одинаковые ID и SHA-256 входов. Сравнение сверяет также хеш зафиксированного контроля. Исходники декодеров читаются из указанных копий.

Для пересборки локального манифеста используй команды `openstt`, `mtedx`, `combine` из `tools/prepare_asr_qa.py`. Первой команде передаются архив OpenSTT, индекс, новая папка и `--exclude` с `development.json` и `holdout.json` из `work/rear-row/corpus/wav` и `work/rear-row/corpus/extra`. Второй — Parquet mTEDx и новая папка. Третьей — новая папка и манифесты OpenSTT, mTEDx и `work/rear-row/corpus/wav/farfield.json` в этом порядке. Прогон проверит хеш пересобранного манифеста.
