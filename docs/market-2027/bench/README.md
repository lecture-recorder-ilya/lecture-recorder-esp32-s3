## Карточки и ключ для наблюдателя

Дать всем системам один WAV. Показывать участнику только вопрос. Попросить ответить и включить слова, которые подтверждают ответ. Время от выдачи вопроса до окончания верного ответа и слышимой цитаты, что наступит позже. Лимит 180 с. Для короткого файла разрешить простое прослушивание целиком. Чтобы не измерять запоминание, назначать один продукт на участника для этого же вопроса. Для 24 участников на полной паре использовать [сбалансированный протокол](../pilot.md).

| Одинаковый вопрос | Ключ | Где искать в оригинале |
|---|---|---|
| Ввод моста уже состоялся или это был план? | Должен прозвучать смысл «согласно плану … войдёт». Слово «введён» меняет статус события. | От 0,0 до 5,8 с |
| На какой месяц и год намечен ввод? | Сентябрь 2017 года. Для зачёта нужны оба элемента. | Начать у 3,8 с, дослушать до 5,8 с |
| Что ожидали завершить к этому моменту? | Бразильские пункты таможенной проверки. Важна оговорка «как ожидается». | Начать у 6,1 с, дослушать до конца |

Интервалы округлены для воспроизведения. Опора — эталон набора и предложенное декодером выравнивание. До поля два слушателя независимо фиксируют ключ на слух. У отрывка нет объявленного ДЗ.
