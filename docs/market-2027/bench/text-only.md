# Карточка для чтения без звука

Выберите строку, которой доверяете, и покажите слова, подтверждающие ответ. К карточке можно вернуться в любой момент. Ответы можно написать, сказать или указать в тексте.

**Вопрос 1.** Мост уже ввели в эксплуатацию или его ещё планировали открыть?

**Вопрос 2.** Какое условие должно было выполниться к указанной дате?

## Текст из эталона FLEURS

**0,0–5,8 с.** Согласно плану мост полностью войдёт в эксплуатацию в сентябре 2017 года,

**6,1–11,16 с.** когда бразильские пункты таможенной проверки, как ожидается, будут завершены.

## Машинный черновик ClipMic

**0,83–5,75 с. Помечено для проверки.** «Согласно плану, мост полностью введён в эксплуатацию с сентября 2017 года,»

**6,19–10,19 с.** «когда бразильские пункты таможенной проверки, как ожидается, будут завершены.»

Текст эталона предоставили авторы русского корпуса FLEURS. В этой карточке для чтения убран двойной пробел, границы округлены. После сверки с исходной записью оценщик вписывает код и дату: __________ . До сверки статус первой версии — «эталон корпуса». Голос или слух участника для выполнения задания не требуются.
