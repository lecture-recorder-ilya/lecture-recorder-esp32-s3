# v0.5.9 и 68f2236 на длинных окнах mTEDx

Архивный замер от 22 ноября 2026 года. В таблицах указаны ревизии, на которых его выполняли. Для версии 0.5.10 нужен отдельный прогон.

Mac Apple M2. Пять одинаковых WAV, 10 мин 29 с, из пяти русских выступлений с оригинальными субтитрами. Первые два источника в настройке, последние три в контроле. Хеши WAV, манифеста и оценщика совпали. Других общих исходных видео с коротким контролем нет. Обе версии использовали одни веса GigaAM v3 ревизии `322c3b29492673eb7d0b434bfa9dfb8653e34d02`, ONNX Runtime 1.24.3 и onnx-asr 0.12.0. Конвейеры `v10-coverage` и `v11-quiet-edges` вернули одинаковый текст, сегменты и таймкоды на всех пяти WAV.

Имена выступающих подтверждены метаданными отдельных видео официального канала TEDx Talks. Поле `speaker_id` в манифесте архива совпадает с ID видео и само по себе не связывает людей между выступлениями. Отдельный список имён добавлен без изменения входа и проверен на пересечение настройки и контроля. [Метаданные выступающих](long-asr-speakers.json) · [Манифест хешей WAV](long-asr-control.json)

## Пересчитать по сохранённым результатам

```sh
python3 tools/compare_lecture_asr.py work/long-asr/control/manifest.json docs/long-asr-control.json \
  work/long-asr/runs/v059-mac.json work/long-asr/runs/68f2236-mac.json \
  --speakers docs/long-asr-speakers.json
```

Для нового кандидата создать собственный JSON командой из инструкции подготовки и подставить его последним аргументом сравнения.
