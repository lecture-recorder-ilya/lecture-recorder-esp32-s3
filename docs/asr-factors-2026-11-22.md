# Пять причин ошибок звука

Архивный замер от 22 ноября 2026 года. В таблицах указаны ревизии, на которых его выполняли. Для версии 0.5.10 нужен отдельный прогон.

Сравнены v0.5.9 и 68f2236 на одних WAV. Для каждого повреждения есть две пары известных файлов: исходные OpenSTT и преобразованные копии. Эталон основного голоса и SHA каждой пары сохранены в JSON. В каждом условии 26 слов.

| Условие | v0.5.9: ошибки / пропуски | 68f2236: ошибки / пропуски |
| --- | ---: | ---: |
| Исходный звук | 0 / 0 | 0 / 0 |
| Слабый голос, −36 дБ | 0 / 0 | 0 / 0 |
| Только отражения до 410 мс | 6 / 6 | 6 / 6 |
| Добавленный фон, SNR 0 дБ | 2 / 1 | 2 / 1 |
| Жёсткий клиппинг около 20% отсчётов | 0 / 0 | 0 / 0 |
| Другой голос, SIR 0 дБ | 22 / 1 | 22 / 1 |

Здесь основная потеря — наложение голосов и отражения; одно ослабление записи ошибки не вызвало. При наложении оценён текст выбранного основного голоса, поэтому слова второго голоса считаются вставками. Ноль ошибок после клиппинга относится только к двум этим фрагментам и не доказывает устойчивость к любому перегрузу. Версии дали одинаковый результат; изменения приложения не сделаны.

**Физическая проверка:** не проводилась. Импульсные отражения и фон смоделированы; реальные микрофоны, расстояния и слушатели не участвовали. Для переноса вывода в аудиторию нужны реальные записи с раздельной разметкой голосов.

Пары WAV и параметры: `work/asr-factors/pairs.json`; полный стенд: `work/asr-factors/`. [Доказательства](asr-factors-2026-11-22.json).

Повторить в новой папке:

```sh

"$python" tools/prepare_asr_factors.py "$repo/work/rear-row/corpus/wav/development.json" \
  --ids lecture-826e1189d0fb lecture-3d89c1cc021f \
  --distractor "$repo/work/clipmic-asr-quality/results/mtedx/clips/CPci7a8l-oU_0001.wav" \
  --output work/factors-repeat
"$python" tools/benchmark_low_snr.py work/factors-repeat/manifest.json \
  --source-root "$repo/work/checkouts/v0.5.9" --output work/factors-repeat/v059.json
"$python" tools/benchmark_low_snr.py work/factors-repeat/manifest.json \
  --source-root "$PWD" --output work/factors-repeat/current.json
```
