# Приложения для телефона · 0.5.3

| Платформа | Пакет | Совместимость | Состояние |
| --- | --- | --- | --- |
| Android | `lecture-recorder.apk` | Android 8.0+; один APK для разных процессоров | Собран и подписан тем же ключом, что 0.5.2 |
| iPhone / iPad | `lecture-recorder-ios-project.zip` | Проект для iOS / iPadOS 16+ | Исходники Xcode; подписанного приложения и TestFlight пока нет |
| Mac | `lecture-recorder-0.5.3-arm64.dmg` | Apple Silicon, macOS 14+ | Установщик и закрытый канал обновлений |

APK не содержит нативных библиотек и не требует отдельных ARM/x86 сборок. Это не подтверждает работу микрофона на каждой модели: разрешения и ограничения фоновой работы зависят от устройства.

## Android: запись без ESP

1. На экране записи выбери **Микрофон телефона**.
2. Нажми **Начать запись** и разреши микрофон.
3. Заверши запись. WAV останется на телефоне; Mac и интернет для записи не нужны.
4. Подключи Mac в настройках. Открой приложение рядом с компьютером: запись перенесётся, затем придут текст и конспект.

При первой установке выбран микрофон телефона. Существующий выбор ESP после обновления сохраняется. Для ESP остаются Bluetooth и Wi-Fi. Запись работает через foreground service с уведомлением и кнопкой остановки. Если микрофон не поддерживает 16 кГц, приложение пробует 48 и 44,1 кГц и пересчитывает звук. На диск сохраняется PCM16 mono 16 кГц.

В библиотеке можно загрузить готовое аудио. Текст, сомнительные места и таймкоды появляются после обработки на Mac.

## iPhone и iPad

Подготовлен отдельный нативный клиент: запись, импорт аудио и видео, библиотека, получение конспекта и текста, прослушивание по нажатию на фразу. Перенос по Wi-Fi использует протокол Mac: подтверждение кода, HMAC, SHA-256, продолжение скачивания и подтверждение сохранения.

Открой [проект iOS](outputs/ios/README.md) в Xcode. Владелец пока не подключил Apple Developer: подписанного IPA, публичной установки и автообновлений iPhone в 0.5.3 нет. TestFlight / App Store — следующий шаг. Архив проекта не устанавливается на телефон как приложение.

## Обновления

- Mac сам находит новую версию в приватном GitHub после однократного входа.
- Android получает APK через сопряжённый Mac. Установку подтверждает системное окно; во время записи обновление откладывается.
- Для iPhone версии будут приходить через канал Apple после его настройки.

## Испытания

Проверяются сборка APK, подпись, очистка, импорт, закрытый канал и перенос APK. Ядро iOS проверяется реальными HTTP-запросами клиента Mac: список WAV, SHA-256, Range, защита от повторов, сохранение текстов и подтверждение переноса с сохранением аудиокопии. Сборка с iOS SDK выполняется отдельным workflow GitHub Actions.

Настоящий Android и iPhone в этой среде не подключены. Тесты протокола и сборка не являются испытанием микрофона, фоновой записи или установки на физическом телефоне.
