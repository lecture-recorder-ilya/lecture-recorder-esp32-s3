# Установка на Mac

В сборке 0.4.1 есть отдельный установщик `lecture-recorder-0.4.1-arm64.dmg`. Python, Homebrew, Xcode и терминал для установки не нужны.

1. Открой DMG и запусти **Установить Запись лекций**.
2. Нажми **Установить и открыть**.
3. Дождись подготовки компонентов. Приложение откроется автоматически.

Следующие запуски — через **Запись лекций** в папке **Приложения** твоего профиля (`~/Applications`). Установка выполняется для текущего пользователя, без пароля администратора. После успешной установки DMG можно извлечь.

## Что нужно

- Mac с Apple Silicon и macOS 14 или новее. Сборки для Intel пока нет.
- Не менее 22 ГБ свободного места перед первой установкой.
- Интернет: установщик загружает Python-пакеты и около 12 ГБ локальных моделей. Скорость зависит от соединения.
- Для больших лекций рекомендуется 16 ГБ оперативной памяти.

Загружаются модели русской речи, Whisper, составления конспектов, чтения фото доски, поиска и голосов преподавателей. Версии пакетов зафиксированы; файлы моделей проверяются по размеру и SHA-256. Распознавание и работа моделей после установки выполняются локально. Перенос с телефона требует соединения с Mac, а загрузка новых версий — интернета.

ESP32 и телефон для самой установки не нужны. Для записи с ESP нужен настроенный микрофон. Сопряжение Android: [PAIRING.md](PAIRING.md). Приложение для iPhone пока не реализовано.

## Пауза и восстановление

Кнопка **Приостановить** завершает установку без удаления библиотеки. Нажми **Продолжить**, чтобы повторить подготовку: загруженные пакеты используются из кэша, части файлов моделей продолжают загружаться с сохранённого места. Повреждённые файлы скачиваются заново.

После установки открой **Восстановить компоненты…** в меню приложения или запусти установщик и нажми **Восстановить**. Он повторит проверки, сохранит записи, расшифровки, расписание и подключение телефона. Во время записи, разбора или сопряжения установка откладывается. Для полного выхода есть команда **Завершить работу**; обычный выход из окна сохраняет работающий сервис записи.

**Журнал установки** открывает подробности ошибки. Если порт приложения занят другой копией, сначала заверши её работу через её меню и продолжи установку.

## Где лежит библиотека

Все компоненты этой установки находятся в `~/Library/Application Support/Lecture Recorder`:

| Путь | Содержимое |
| --- | --- |
| `project/outputs/recorder/recordings` | Аудиозаписи |
| `project/outputs/recorder/analysis`, `study`, `lessons` | Тексты и материалы занятий |
| `project/work` | Модели, окружения и настройки подключения |
| `install.log` | Журнал установки |
| `Установить Запись лекций.app` | Восстановление компонентов |

Приложение в `~/Applications` ссылается на управляемую копию. Повторная установка не заменяет личные данные. Другая копия приложения в этой папке сохраняется; при конфликте ярлык называется **Запись лекций — локальная**. Библиотека из старого исходного проекта автоматически не импортируется.

## Распространение

Эта сборка подписана локально и не прошла notarization Apple. Для публичного распространения с обычным первым запуском через Finder нужны Developer ID и notarization; в текущем окружении такого сертификата нет. Защита macOS не отключается.

Установка компонентов проверена на Apple Silicon с macOS 27. Совместимость минимальной версии macOS отдельно на устройстве не проверялась. Готовые сборки и ограничения доступа описаны в [UPDATES.md](UPDATES.md).

## Сборка установщика разработчиком

```sh
python3 tools/build_installer.py
```

Нужны Apple Silicon, Python для сборочного скрипта, Xcode Command Line Tools и интернет. Скрипт получает проверенную версию uv, отдельный Python 3.12.12, собирает приложения и создаёт DMG в `work/installer`. В DMG входят код, Python и загрузчик; веса моделей и личные данные не включаются. Манифесты и зафиксированные зависимости находятся в `installer`.
