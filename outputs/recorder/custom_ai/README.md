# Собственный ИИ для лекций — экспериментальный этап

Задачи: распознавание русской речи и извлечение целых фрагментов конспекта, ДЗ, формул, названия предмета и имени преподавателя. Обе сети начинают обучение со случайных весов. Код не загружает готовые модели. PyTorch используется как библиотека вычислений и обучения.

Речевой прототип: фиксированные log-mel признаки, свёртка, двунаправленная GRU и CTC, 526759 параметров (~2 МБ весов float32). Текстовый прототип: байтовое представление, GRU и пять независимых меток, 97397 параметров (~0,4 МБ). Размеры относятся только к весам: для выполнения и обучения нужна дополнительная память и установленный PyTorch. Это небольшие исследовательские прототипы, их ёмкость и качество на лекциях ещё не доказаны.

Страница подготовки примеров открывается в приложении: **Настройки → Наш ИИ → Подготовить учебные примеры**. Прямой адрес: http://127.0.0.1:8769/ после запуска службы. Служба слушает только локальный адрес Mac, проверяет Host и Origin, не публикует учебные данные.

1. Выбрать сохранённую запись и законченный фрагмент 0,5–20 секунд.
2. Прослушать, вручную записать точный текст и отметить содержание. Для неразборчивого фона/тишины сохранить пустой текст с отдельной отметкой.
3. Подтвердить проверку. Автоматические расшифровки не импортируются как эталоны.
4. Собрать примеры минимум из трёх независимых занятий. Файлы одного занятия и объединённые записи с исходными частями остаются вместе при разделении данных.
5. Кнопки запускают пробное обучение одной модели. Есть остановка. Порог 20 примеров проверяет только работоспособность процесса и не означает достаточный объём для качественного ИИ.

Данные, извлечённые WAV, журналы, результаты и веса сохраняются в игнорируемом `work/custom-ai`; исходные лекции не изменяются. Контрольные суммы защищают учебное аудио от незаметной подмены. Каждый эксперимент сохраняет свой снимок обучающих и контрольных примеров, исходный seed, происхождение весов, показатели и лучший кандидат.

Для речи измеряются ошибки слов (WER) и доля фрагментов тишины с выдуманным текстом. Для разбора — micro-F1 меток и их покрытие. Пока нет сравнения на большом отдельном контрольном наборе с действующей системой, кандидат имеет `production_ready=false` и не включается в приложение.

Текстовая модель выбирает исходные фрагменты целиком. Генеративный пересказ, полноценное понимание математического решения и преобразование диктуемой формулы в LaTeX ещё не реализованы. Речевой прототип офлайн; потоковое распознавание, экспорт для телефона и производственная интеграция ещё предстоят. Собственный большой генеративный анализатор потребует отдельного корпуса правильных разборов лекций.

Ручной запуск из `outputs/recorder` с установленными numpy и PyTorch:

```sh
../../work/ai-env/bin/python -m custom_ai.server
../../work/ai-env/bin/python -m custom_ai.train speech --epochs 30
../../work/ai-env/bin/python -m custom_ai.train notes --epochs 30
../../work/ai-env/bin/python -m custom_ai.predict /path/to/run/candidate.pt --audio /path/to/clip.wav
../../work/ai-env/bin/python -m custom_ai.predict /path/to/run/candidate.pt --text /path/to/passages.txt
```

Текущий статус: **ядро и подготовка данных готовы; пользовательских проверенных примеров пока нет; собственные модели на лекциях не обучены**. Готовые распознаватели и действующее приложение продолжают работать до доказанного качества замены.
