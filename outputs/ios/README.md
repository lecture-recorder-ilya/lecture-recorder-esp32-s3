# Запись лекций для iPhone и iPad

Нативный клиент для iOS / iPadOS 16+. Запись встроенным микрофоном, импорт аудио и видео, библиотека, конспект и расшифровка с таймкодами, прослушивание по нажатию на фразу. Распознавание и очистку выполняет сопряжённый Mac.

## Состояние

Проект входит в 0.5.7 отдельным архивом исходников. Это не устанавливаемый IPA и не ссылка TestFlight. У владельцев проекта пока нет Apple Developer. Подписанного выпуска для iPhone ещё нет.

Проверка сборки для симулятора и iPhone без подписи выполняется в GitHub Actions: «Сборка приложения iPhone». Проверки WAV и обмена с Mac запускаются локально через `work/test_ios_core.py`. Сборка не заменяет испытания микрофона, фоновой записи, локальной сети и сертификатов на настоящем устройстве.

## Открыть проект

В Xcode открой **LectureRecorder.xcodeproj**. Для запуска на собственном устройстве выбери свой Team в **Signing & Capabilities** и свой iPhone в качестве устройства. Для распространения через TestFlight или App Store нужен Apple Developer и настройка приложения в App Store Connect.

## Подключение к Mac

1. На Mac открой **Настройки → Телефон и Mac → Подключить телефон**.
2. На iPhone открой **Настройки** приложения. Введи показанный адрес Mac и его 12-символьный код.
3. Разреши доступ к локальной сети. Сравни цифры на обоих экранах и подтверди подключение на Mac.
4. Оставь приложение открытым рядом с Mac в общей Wi-Fi сети. Перенос и получение текста происходят автоматически.

Подключение хранится в Связке ключей iPhone. Во время сопряжения проверяется код сертификата Mac; постоянное доверие произвольным сертификатам не включается. Для обмена используется тот же протокол HMAC, что у Android. Проверяются время, одноразовый nonce, тело запроса и диапазон загрузки. Повторы и неподписанные запросы отклоняются.

После подтверждения контрольной суммы Mac запись остаётся в локальной библиотеке iPhone. При прерывании записи черновик сохраняется; его можно восстановить из библиотеки. Разрыв переноса не удаляет исходное аудио. iOS может приостановить передачу в фоне; для синхронизации открой приложение. USB и Bluetooth для iPhone в этой версии не реализованы. ESP для записи микрофоном телефона не нужна.

Новые версии iPhone-клиента будут распространяться через TestFlight или App Store, после настройки канала Apple. APK с GitHub предназначен только для Android.

Документация Apple: [запись аудио](https://developer.apple.com/documentation/avfaudio/avaudiorecorder), [фоновая запись](https://developer.apple.com/documentation/avfaudio/avaudiosession/category-swift.struct/record), [распространение](https://developer.apple.com/documentation/xcode/distributing-your-app-for-beta-testing-and-releases/).
